# Warehouse HUD sprites, version 1

Generated with the built-in imagegen tool for the warehouse HUD review. All sprites have transparent surroundings. Runtime text, numbers, and animation timing are drawn by LÖVE.

- `cash-display.png`: front-facing dark green enamel counter with aged brass frame and blank center for yellow calculator digits.
- `flowing-bill.png`: one fictional worn sage-green banknote used as the moving cash sprite.
- `calendar.png`: blank ivory tear-off calendar with red header, two metal rings, and no printed date.
- `alarm-clock.png`: blank dark green tabletop alarm clock with a recessed display for time digits.
- `notice-banner.png`: narrow smoked green note banner with subtle ink texture and brass details, with blank center for notification text.
- `menu-panel.png`: upright matching green menu panel with blank center for the three actions.
- `vehicle-status.png`: wide motorcycle dashboard frame with blank dark leather center for live condition, mileage, fuel, and lighting telemetry.

Prompt set: each sprite was requested as a single orthographic hand-painted game UI asset, with no baked-in text, numerals, watermark, scene background, or external shadow. The cash frame reserved a quiet interior for overlaid digits; the bill was isolated for directional animation; the calendar and clock reserved blank faces; the notice, menu, and vehicle surfaces reserved quiet dark centers for live text. The calendar was also tried as a cleanup edit to remove edge speckles; the original was retained because it matched the game better.
