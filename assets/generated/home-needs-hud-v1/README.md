# Home personal needs HUD sprite

`personal-needs-panel.png` was generated with the built-in imagegen tool as a new transparent bitmap, using `warehouse-hud-v1/vehicle-status.png` and `warehouse-hud-v1/notice-banner.png` as style references. The prompt requested dark green enamel and brass, four ordered pictograms (food, water, soap, moon), blank live-value wells, and no baked-in words or numbers. LÖVE draws the title, live bars, values, and action hints over the sprite.
