# Break room mini game sprite prompts

All images were generated with the built-in ImageGen tool on October 9, 2026. Transparent output was requested for every image except the opaque Critter Kombat stage. The rabbit action atlas used the Picture Shop rabbit idle strip as its edit reference. The fighter atlas used Mouse Frontier's tinker fox and cowboy mouse sprites as edit references; those original files were not copied into this project.

This reusable prompt set uses the corrected title **Critter Kombat**. The cabinet marquee is blank and the stage has no words, so title lettering remains a runtime UI element.

> Use case: stylized-concept. Asset type: transparent 2D world prop sprite for The Picture Shop's break room. Warm hand-painted industrial game art: teal-white smooth rink under glass, orange and dark steel trim, compact sturdy legs, small end goals and two subtle mallets resting on the surface. Match the scale and perspective of a warehouse break room with concrete floor, steel beams, kitchenette and brown lounge furniture. Composition: single full object centered, all legs visible, leave even transparent margin; oblong table angled gently so both goals and playing surface read clearly at small game scale. Lighting: warm overhead warehouse light. Constraints: actual alpha transparency, no backdrop, no room, no people, no painted shadow, no labels, no logos, no text, no border, no extra objects. Preserve a crisp readable silhouette suitable for later sprite packing.
