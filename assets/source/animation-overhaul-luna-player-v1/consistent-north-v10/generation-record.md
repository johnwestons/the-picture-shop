# North V10 support-foot reach test

This is a rejected, review-only ImageGen test for a true North planted-foot track. It does not change the installed V7 strip. References are the isolated V7 phases in `output/animation-overhaul/player-north-v10/`.

The North view is drawn at `0.30 * 256 / 412 = 0.1864` world units per source pixel. At the current 20-world-pixel pose spacing, a support sole must move about 107 source pixels from contact to weight-down to stay at the same world point. The current 512px cell has 47 pixels below its y=465 anchor, equivalent to only 8.8 world pixels. The fixed square frame therefore cannot show the required reach.

This pose is the next instant after the first: the viewer-left boot remains the same planted left boot, while the root has advanced 20 world pixels north. To test true foot contact, extend that support leg naturally behind the pelvis so its sole sits about 107 pixels lower than the contact sole in 512px-source coordinates; the viewer-right boot stays the passing/free leg. Preserve the torso and head proportions; only reshape the legs/trousers as a believable weight-down stance. Isolated single character, transparent background, no scene, no shadows, no ghost poses, no extra limbs, no duplicate feet, no text, no colored red or green edging. The character may extend below the square reference, with transparent canvas below the body so the full support boot is visible.”

**V2:** “Generate a single intentionally extended North rear-view rabbit-worker WEIGHT-DOWN pose for a sprite reach test. The viewer-left/character-left boot is the planted support boot; the viewer-right boot is free and lifted behind. Keep the reference's head, ears, torso, overalls, belt, white tail, tool pouch and arms at exactly the same visual scale and proportions. The full silhouette should be visibly about 25% taller only because of that one extended leg, not because the whole character is enlarged. Use clean black ink outlines and matching blue fabric folds. No background, extra legs, extra ears, text, shadows, pose ghosts, red/magenta/green fringe or colored edge glow.”

**V3:** “Refine the North rear-view rabbit-worker weight-down pose from the second reference using the first reference as the exact identity and size guide. The last version extends the viewer-left support leg too far; shorten only that extended trouser-and-boot length by about one quarter, keeping the head, torso, arms, pouch, tail, colors and outline scale consistent with the first reference. At matched head width, make the viewer-left planted sole land exactly about 107 pixels below its normal contact sole in the 512px source coordinate system, corresponding to 20 world pixels of root advance. Keep the viewer-right free boot bent and lifted. One character, transparent background, entire stretched boot visible, no scene, no extra limbs, no text, no shadows, crisp black outline with no red/magenta/green edge glow.”

All three generated tests have red/green fringe pixels only at alpha 1–8; none remain above alpha 8. The current V7 source also contains low-alpha edge colors: unchanged phases match V6, while the new phases contain five green and one red pixel in that range. These pixels are not visible in the 32 production-renderer captures at game scale. The ImageGen cleanup attempt was rejected because it redrew the strip and introduced stronger colored edges.

## Rectangular atlas runtime support

The runtime loader now accepts explicit frame width/height, columns/rows, frame count, and an optional body-core normalization height through `Config.characterActionFrameLayouts`. `src/tests/character_animation_test.lua` covers a 4096x704, 16-column by 2-row layout of 256x352 frames, legacy square-strip compatibility, quad coordinates and normalization. A first renderer regression exposed missing grid aliases in loaded metadata; that was fixed, and the installed V7 walk passed 32 production-renderer captures plus the animation-focused smoke suite. No rectangular North art has been approved or installed.

## Next art gate

Do not fit these raw images into the installed 512px square strip. A viable art test needs the North body's core height to remain about 205px after half-resolution registration, while extending the support sole roughly 107px below its contact location. A 256x352 frame provides that space at the existing 77-world-pixel character height. A 32-pose, 16-column by 2-row atlas would be 4096x704; each pose would advance 5 world pixels, keeping the existing 160px physical stride and about 116 steps per minute while reducing per-frame foot travel to roughly 13 source pixels. Rectangular atlas loading and body-core normalization are now supported, but art still needs to be authored at the existing head/torso scale. Preserve the 512px V7 art and validate the planted track in the production renderer before installation.
