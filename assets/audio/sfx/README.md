# The Picture Shop sound effects

Foley-style effects assembled by `tools/generate_sfx.py`. The shipping palette
uses attributed Creative Commons recordings documented in
`assets/audio/SOURCES.md`, plus filtered air and friction noise. It contains no
musical confirmation tones, oscillators, synthetic motor notes, or resonant
chimes.
All files are mono, 44.1 kHz, 16-bit PCM WAV and can be loaded directly by LÖVE.

| File | Intended event |
| --- | --- |
| `ui_click.wav` | Ordinary button or menu selection |
| `ui_confirm.wav` | Accepted action or successful order |
| `ui_error.wav` | Blocked or invalid action |
| `cash_sale.wav` | Payment or machine sale |
| `job_complete.wav` | Entire customer job completed |
| `loading_door.wav` | Loading-bay door movement |
| `truck_arrival.wav` | Truck backing into the dock |
| `pallet_pickup.wav` | Pallet jack lifting a pallet |
| `pallet_place.wav` | Pallet or machine placement |
| `cutter_clamp.wav` | Polar cutter clamp engagement |
| `cutter_cut.wav` | Polar cutter blade cycle |
| `press_start.wav` | Heidelberg Windmill startup |
| `press_running_loop.wav` | Seamless Windmill production loop |
| `wrapper_cycle.wav` | Full skid-wrapper cycle |
| `maintenance_tool.wav` | Successful maintenance interaction |
| `warehouse_ambience_loop.wav` | Seamless low warehouse room tone |
| `picture_shop_sfx_preview.wav` | Audition reel in the order above |
