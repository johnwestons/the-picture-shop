# Lobby furniture edit

The active `assets/generated/warehouse-lobby-seating-v4.png` smooths the expansion passage, lounge wall seam, and nearby floor texture after the v3 entrance revision.

The seating edit is retained in `assets/generated/warehouse-lobby-seating-v2.png` (1536 × 1024) as the base for the current `assets/generated/warehouse-lobby-seating-v3.png` entrance revision. The coffee table, legs and shadow are removed. The brown leather couch has two broad cushion surfaces, a lower back, slimmer arms and an open front so seated clients' knees, shins and shoes read clearly. The couch was refined around the existing left/right hip contacts at `(754,176)` and `(794,185)` in the 960 × 678 game canvas. Character sprites, seat coordinates and walking approaches are unchanged.

Only the couch and former table/rug region was replaced. `tools/integrate_lobby_seating_v2.ps1` installs the reviewed ImageGen edit through two local polygons with a three-pixel inward feather inside the lobby crop `(1096,210,224,144)`. It verifies every source pixel outside that crop remains identical. The integration changed 12,531 lobby pixels and zero pixels elsewhere; surrounding office fixtures, platform borders, walls, painting, plant, chairs, loading dock, storage racks and production floor keep the original source pixels outside the small edit mask. The original warehouse file is retained.

The edit and refinement used the built-in ImageGen tool. Inputs, original lobby crop, reviewed edited artwork, exact prompts (`prompt.txt`, `refine-prompt.txt`), source hashes and integration details (`integration.json`) are saved in `assets/source/lobby-seating-v2/`. The installer refuses unreviewed changes to either source hash.

The runtime also removes the coffee table's collision box and both couch/table foreground masks from `src/warehouse_registration.lua`. Removing the old foreground masks is necessary: restoring background pixels through those polygons after drawing a client would erase the newly visible legs even though the table no longer exists in the artwork. Armchair foreground rendering remains in use.

The client seating checks render every business character in both couch positions and both chairs, including arrival, blink, review, host/guest pose matching and departure. They now also check that the table has no collision, no stale mask and an open floor approach. In-game desktop/mobile and neutral/blink previews are saved in `output/lobby-seating-v2/` when `PICTURE_SHOP_SEATING_CAPTURE_DIR` points there.

Validation: the final client seating focus passed 690 checks and the warehouse alignment focus passed 713 checks, including real navigation, all four reception positions, room art/masks, visible interactions, employee exits and pallet transport. The old table collision fixture now checks the sofa itself; the room-art contract names the active lobby-edited sprite. All six couch/client combinations were visually reviewed, along with both clients together and the desktop/mobile views. Unrelated changes in the shared workspace were retained.
