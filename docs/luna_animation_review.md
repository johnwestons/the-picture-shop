## Acceptance responsibilities

Root checks species anatomy and appendage ownership, camera, outfit and tool sides, pose sequencing against both neighboring frames, body proportions, stable support feet and work contacts. A unique pixel hash or an alpha-bounds pass does not prove correct motion. New frames must subdivide the original stride distance and preserve the eight canonical gait phases. Work actions need update-time sequencing tied to real operations; drawing must not mutate state.

All raw sources and rejected variants stay separate from normalized candidates and runtime assets. Keep exact prompts, reference roles, selected cells and hashes. A successful generation is still a candidate until root reviews the complete sequence and its production-renderer integration.
