# Android 46 audit — October 8, 2026

This update includes the open-office warehouse, separate storage/break/utility
rooms, employee pallet-jack transport, directional animation, navigation and
stock-consumption changes that were pending in the working tree.

## Fixes found during the audit

- Scene navigation adapters were rebuilt and nested repeatedly. Adapters now
  reuse stable masks, preserve the original asset owner, and keep navigation
  caches useful during long sessions and room transitions.
- Switching saves while a wrapper was running could leave its old pallet and
  active cycle in the new shop. Session teardown now creates a fresh wrapper.
  The in-game reset button still protects an active cycle from interruption.
- Side-view forklift lift travel still used the old expansion-room shelf
  height. It now matches the registered lower and upper warehouse decks.
- Room textures now participate in the normal cache pruning/focus cleanup.
  The opening dock reuses one mesh instead of allocating a GPU mesh every frame.
- Player collision substeps share one obstacle snapshot per controller update;
  the next update refreshes it so moving stock and actors remain obstacles.
- Updated obsolete hand-carried employee fixtures and shelf geometry checks.
  Employee scene captures support stencil rendering and packaged test runs.
- Fixed the performance launcher reporting a successful process as a failure
  because its exit handle had not been retained/refreshed.

All game tests use isolated disposable test identities. Ordinary game saves
were not deleted or backed up.

The desktop performance probe measured approximately 0.25 ms p95 for world
updates and 0.23 ms p95 for world draws in its representative scene. These are
CPU measurements on this PC, not phone frame-rate claims. First-time forklift
direction texture loads remain visible spikes (up to roughly 68 ms here).
Warm navigation, normal drawing and idle hosting avoid per-frame disk reads;
an empty host creates no unnecessary shop snapshots.

## Phone update

Version name: `0.1.0-android.46`; version code: `46`;
application ID: `com.thepictureshop.game`; multiplayer protocol: `30`.

The APK build verifies its manifest, signature, embedded game archive, native
libraries and 16 KB alignment. The share report records the final SHA-256,
source commit and comparison against the previous installer's signing key.
Install over the existing app to update. Both phones and any PC host must use
the matching game revision. Direct Internet play remains at its existing
engineering status; this audit does not certify it for production use.

No physical Android device was connected. Real-device background suspension,
phone-to-phone Wi-Fi/USB tethering and performance still need device testing.
Loopback sockets and simulated impairment tests do not establish those results.

From PowerShell at the repository root:

```powershell
$env:PICTURE_SHOP_PROBE_ROOT = (Get-Location).Path
& 'C:/Program Files/LOVE/lovec.exe' tools/lan_loopback_probe
```

`PICTURE_SHOP_PROBE_PORT` to another unused port if necessary. The ordinary
performance probe is `tools/run_performance_probe.ps1`.
