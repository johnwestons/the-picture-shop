# Warehouse first-person archive

This folder preserves the warehouse interior first-person development test.
The implementation and notes are documented in
[`docs/warehouse_first_person_experiment.md`](../../docs/warehouse_first_person_experiment.md).

Archived code and assets are outside the game package's copied `src` and
`assets/generated` trees. Restore files to those original paths before
reconnecting the experiment to the game.

The old lab review renders and generated atlas studies are in
`output/warehouse-perspective-lab/`.
