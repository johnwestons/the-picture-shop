THE PICTURE SHOP - PRIVATE TEST RELEASE

Choose exactly one download for each device:
- Windows 10/11 x64: ThePictureShop-Windows-Setup-*.exe
- Android 8.1 or newer: ThePictureShop-Android-*.apk

All devices in one multiplayer session must use files from this same numbered
release. SHA256SUMS.txt contains the expected fingerprint for each download.

This is a private test build. It is not code-signed for public distribution, so
Windows or Android may display a reputation warning. Confirm the download came
from the private tester release before running it.

Use LOCAL PLAY for same-network multiplayer. DIRECT PLAY remains disabled while
its production security and wider network acceptance work is unfinished.
