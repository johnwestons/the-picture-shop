THE PICTURE SHOP - WINDOWS TEST BUILD

Install
1. Run ThePictureShop-Windows-Setup-*.exe.
2. Windows may warn that this private test build is not code-signed. Confirm the
   file came from the private release link before continuing.
3. The installer is per-user and does not require administrator access.

Multiplayer
- Use LOCAL PLAY for devices on the same Wi-Fi or local network.
- Every device must use the same test version.
- Windows Firewall may ask whether to allow the game on private networks when
  hosting. Do not disable the firewall and do not allow public networks merely
  to make a LAN test pass.
- DIRECT PLAY remains an engineering feature and is not enabled in this build.

Updates and saves
- A newer installer can be installed over an older tester build.
- Uninstalling removes the application but intentionally preserves saved games.
- Please include the displayed version and the exact on-screen message with a
  bug report. Do not share invitation codes or public network addresses.
