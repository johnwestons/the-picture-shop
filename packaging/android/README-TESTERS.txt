THE PICTURE SHOP - ANDROID TEST BUILD

Install
1. Download ThePictureShop-Android-*.apk directly onto the phone.
2. Open the APK and allow installation from that download source if Android asks.
3. Install over an older tester build to retain its saved games.

Android and Play Protect may warn about a privately distributed test APK. Verify
the file came from the private release link and compare its SHA-256 checksum before
continuing. Do not uninstall an older build first unless its saves are expendable.

Multiplayer
- Use LOCAL PLAY for devices on the same Wi-Fi or local network.
- Every device must use the same numbered test release.
- Keep the Android host in the foreground with its screen awake for the session.
- DIRECT PLAY remains an engineering feature and is not enabled in this build.

Bug reports
Include the phone model, Android version, test-build version, and exact on-screen
message. Do not include invitation codes, public addresses, or private save files.
